# Localization

English and French, like the web app, with the same message files.

## Where text lives

```
l10n/en/auth.json          { "AuthForm": { "email_label": "Email address", … }, "SignInPage": { … } }
l10n/fr/auth.json          the same keys, in French
lib/l10n/arb/app_*.arb     GENERATED by `make l10n` (committed)
lib/l10n/gen/              GENERATED by gen-l10n (git-ignored; `flutter pub get` rebuilds it)
```

The JSON files use the web app's shape (`src/locales/*.json` in nextjs-boilerplate): namespaces
of ICU messages. Most core namespaces were copied from it, so the two apps say the same thing.
One file per feature keeps diffs and reviews small.

`Namespace.key_name` becomes the getter `namespaceKeyName`:

```dart
Text(context.l10n.authFormEmailLabel)                     // AuthForm.email_label
Text(context.l10n.dashboardPageHelloMessage(user.email))  // "Hello {email}!"
Text(context.l10n.authFormErrorRateLimited(minutes))      // {minutes, plural, one {…} other {…}}
```

## Workflow

1. Edit `l10n/en/<file>.json` **and** every other locale.
2. `make l10n` — merges the JSON into ARB files, checks the locales, runs gen-l10n.
3. Commit the JSON and `lib/l10n/arb/*`.

`make lint` (and CI) fails when a locale misses a key or has one English doesn't, when
placeholders differ between locales, or when the ARB files are out of date.

## Messages

ICU syntax, as in the web app:

| Need | Write | Dart |
|---|---|---|
| A value | `"Hello {email}!"` | `l10n.x(email)` (`String`) |
| Plural | `"{count, plural, =0 {No files} one {# file} other {# files}}"` | `l10n.x(count)` (`int`) |
| Choice | `"{kind, select, admin {Admin} other {User}}"` | `l10n.x(kind)` (`String`) |
| A number | `"VAT ({rate, number, percent})"` | `l10n.x(0.2)` → "VAT (20%)" |
| Markup | `"Based on <upstream>Next.js Boilerplate</upstream>."` | `RichMessage(l10n.x, tags: {'upstream': (t) => TextSpan(…)})` |

The tool turns `#` into the plural's own placeholder and `{x, number, style}` into a typed
placeholder, which gen-l10n doesn't support directly.

Dates and numbers outside messages: `context.formatDate(…)`, `formatDateTime`, `formatTime`,
`formatNumber` (intl, in the current locale and the phone's time zone).

## Adding a language

1. `AppConfig.locales`: add `Locale('th')`.
2. `cp -r l10n/en l10n/th`, translate every file.
3. `make l10n`.
4. iOS: add the code to `CFBundleLocalizations` in `ios/Runner/Info.plist` (and translated
   permission texts, see [phone features](device-features.md#ios-permission-texts)).
5. Fonts: Libre Franklin and Kalam cover Latin scripts only. For Thai (or another script) add a
   font with those glyphs to `pubspec.yaml` and to `fontFamilyFallback` in `app_theme.dart`.

The language follows the phone unless the user picks one in Settings.
